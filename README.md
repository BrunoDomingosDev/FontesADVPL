# FontesADVPL
Repositório destinado ao armazenamento e versionamento de **fontes ADVPL** utilizados em customizações do **ERP Protheus**. Contém rotinas, pontos de entrada, relatórios, integrações e utilitários desenvolvidos para atender regras de negócio e automações. O objetivo é organizar, manter e evoluir o código com controle de versão.
